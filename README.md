# Typonaut

Eine Lern-App für [lernapps.net](https://lernapps.net): das Zehnfingersystem lernen auf einer Reise durch den Weltraum.
Wörter fliegen als Kometen auf das Raumschiff zu und werden abgetippt, bevor sie ankommen. Kapitel für Kapitel kommen
neue Tasten dazu, auf Deutsch (QWERTZ) und Englisch (QWERTY). Für Kinder ab Klasse 3, ohne Vorwissen. Du brauchst eine
Tastatur.

Die App läuft im Browser, braucht kein Konto, sammelt nichts und speichert Sterne und Sternenstaub nur auf dem Gerät.

- Spielen: <https://mrsimpson.github.io/typonaut/>
- Entwickeln: `npm install`, dann `npm run dev`; `npx lernapps check` führt alle Prüfungen aus.
- Inhalte (Kapitel, Wörter, Sprachen): `src/data/`, Anleitung dazu in `.agents/skills/app-content/SKILL.md`.
- Die Reihenfolge der Tasten orientiert sich an der Schulpraxis, zum Beispiel am
  [Leitfaden Tastaturschreiben des Kantons Schwyz](https://www.sz.ch/public/upload/assets/65825/Leitfaden_Tastaturschreiben.pdf) (2024).
